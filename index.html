ui-vuivui

Web Component vui vẻ cho các thao tác thường gặp. Mỗi thẻ làm việc thật — chỉ có lớp “da” là trò chơi.

🏀 Ném file vào rổ 🎯 Bắn OTP bằng ná GitHub

Ném file vào rổ · <vv-basket-upload>

Kéo file từ máy vào thẻ (hoặc bấm nút — trên điện thoại chỉ có cách này) — file thành quả bóng và bay vào rổ.

Thử nghiệm

Âm thanh bật/tắt bằng nút loa trên thẻ. Bật “Giảm chuyển động” trong cài đặt máy để xem chế độ không hoạt hình.

Sự kiện


          

          

            
Cách dùng


import { xhrUploader } from 'ui-vuivui';
const up = document.querySelector('vv-basket-upload');
up.uploader = xhrUploader('/api/upload', { fieldName: 'file' });
up.addEventListener('vv-uploaded', (e) => console.log(e.detail.result));

<vv-basket-upload multiple sound accept="image/*" max-size="10MB">
</vv-basket-upload>

          

        

      

    


    
    

      
Bắn OTP bằng ná · <vv-slingshot-otp>

      
Giữ một số, kéo xuống để căng dây và nhắm — đường chấm xanh là sẽ trúng ô. Chạm nhẹ một số để bắn tự động, hoặc gõ / dán mã.

      

        
        

          

            
Thử nghiệm

            
Mã đúng của máy chủ demo: 

            
Trong app thật, mã được gửi qua SMS/email và chỉ máy chủ biết. Thẻ không bao giờ báo đúng/sai từng chữ số — chỉ kiểm tra cả mã một lần.

            
            
            
            

          

          

            
Sự kiện

            

          

          

            
Cách dùng


import { jsonVerifier } from 'ui-vuivui';
const otp = document.querySelector('vv-slingshot-otp');
// Máy chủ nhận { code } và trả { ok: true|false, message? }
otp.verifier = jsonVerifier('/api/otp/verify');
otp.addEventListener('vv-continue', () => location.href = '/app');

<vv-slingshot-otp length="6" name="Lan" sound></vv-slingshot-otp>
